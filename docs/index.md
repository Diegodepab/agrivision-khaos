# AgriVision Khaos

Bienvenido a la documentación técnica del pipeline de curación de datos federado **AgriVision Khaos**.

Este framework de *Data-Centric AI* está diseñado para sistematizar el procesamiento, limpieza y etiquetado masivo de imágenes agrícolas, garantizando que los modelos de Machine Learning (como las redes convolucionales o visual transformers) se entrenen sobre una verdad fundamental (Ground Truth) impecable.

## Filosofía del Proyecto

En la IA moderna, el cuello de botella rara vez es la arquitectura de la red neuronal, sino la calidad de los datos subyacentes. Este repositorio automatiza la detección de problemas endémicos en datasets públicos y de campo:

- **Resolución Insuficiente**
- **Desenfoque y Ruido**
- **Marcas de Agua y Textos (OCR)**
- **Artefactos de Estiramiento (Smearing)**
- **Fuga de Datos (Duplicados semánticos)**
